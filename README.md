Tableau Level 1 – Task 2: City Restaurant Count

Project Overview

This project analyzes restaurant data using Tableau Public to identify the number of restaurants in different cities.

Objective

- Identify the cities with the highest number of restaurants.
- Compare restaurant counts across different cities.
- Visualize city-wise restaurant distribution using a bar chart.

Tools Used

- Tableau Public
- Restaurant Dataset

Visualization

City-wise Restaurant Count Bar Chart

Key Insights

- Identified cities with the highest restaurant counts.
- Compared the distribution of restaurants across cities.
- Created a visualization to understand restaurant concentration.

Files Included

- Tableau workbook (.twbx)
- Dashboard screenshot (.png)
- README.md

Conclusion

This project helps understand restaurant distribution across cities and identify cities with the highest restaurant concentration.
